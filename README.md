# riml-ds

riml のプロダクト群（qrcc・noter …）が共有するデザインシステムとコンポーネントライブラリ。

| 領域       | パッケージ                                                     | 中身                                           |
| ---------- | -------------------------------------------------------------- | ---------------------------------------------- |
| システム   | `@riml-ds/tokens`, `@riml-ds/css`                              | DTCG トークン、基礎 CSS、ガイドライン、DESIGN.md |
| ライブラリ | `@riml-ds/elements`, `@riml-ds/react`, `@riml-ds/vue`, `@riml-ds/svelte`, `@riml-ds/astro` | Lit Web Components と生成ラッパー |
| ツール     | `@riml-ds/lint`, `@riml-ds/mcp`                                | 利用側で使う lint 設定と MCP サーバ            |

- 使い方: `skills/riml-ds/SKILL.md`（エージェント向け）/ Storybook（GitHub Pages）
- 設計: `docs/architecture.md`、`docs/adr/`、`DESIGN.md`
- 開発: `CLAUDE.md`
