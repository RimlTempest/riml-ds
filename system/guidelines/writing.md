# 文言

- 短く、動詞で始める：「保存」「共有リンクを作成」「削除」。名詞止めの「保存する」は使わない。
- 主語を省く。「あなたの」「私たちの」を書かない。
- 敬体は**エラー文と確認文だけ**：「削除すると元に戻せません。削除しますか？」。
  ラベル・ボタン・見出しは常体か名詞。
- エラーは「何が起きたか」+「どうすればいいか」。原因が分からないときは「もう一度試す」を提示する。
  「エラーが発生しました」「不正な値です」は禁止。
- 数字は半角、単位との間にスペース無し（`44px`、`3 件` は例外的にスペースあり）。
- 三点リーダーは「…」1 文字。「...」は使わない。
- 状態を表す語は統一：読み込み中 / 保存済み / 未保存 / オフライン / 再接続中。
- 英語の UI 文言（`lang="en"` の利用側）では sentence case。Title Case は使わない。
- 絵文字を UI 文言に使わない（読み上げが崩れる）。アイコンは SVG に `aria-hidden`、意味は文言で。
