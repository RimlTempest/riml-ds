# 文字

`@rimltempest/riml-ds-css` の `typography.css` が出すクラスの使い分け。
実値の真実源は `system/tokens/src/**/typography.tokens.json`、見本は Storybook の
`Foundations/Typography`。書体そのものの決めごとは [docs/brand.md](../../docs/brand.md) §6 にある
（**Web フォントは同梱しない**。`font.family.display` は入っていれば効く丸ゴシック系のスタック）。

## 構造とクラスを分ける

見出しの**階層は要素**（`h1`..`h6`）が、**大きさはクラス**が決める。両者は独立している。

```html
<h2 class="rd-heading-3">今週の同期</h2>
```

- 見出しレベルは文書の構造で決める。飛ばさない（`h2` の次に `h4` を置かない）。
- 「小さく見せたいから `h4` にする」をしない。要素はそのままでクラスを下げる。
- 素の `h1`..`h6` は `base.css` が持つ。`typography.css` は触らない。

## 段

| クラス                            | 使うところ                                                   |
| --------------------------------- | ------------------------------------------------------------ |
| `.rd-display`                     | ヒーロー、数字ひとつの窓。**1 画面に 1 つだけ**              |
| `.rd-heading-1` … `.rd-heading-4` | 見出しの大きさ 4 段                                          |
| `.rd-body`                        | 本文                                                          |
| `.rd-small`                       | 補助テキスト（注記・単位）。本文より小さくしてよい下限（14px）|
| `.rd-caption`                     | 補助文。広い字間と `text.muted`                              |
| `.rd-label`                       | 太字の小さいラベル                                            |
| `.rd-mono` / `.rd-numeric`        | 等幅・桁揃え（`tabular-nums`）                               |

`display` を 2 つ置くと、どちらも「いちばん大事」でなくなる。2 つ要ると思ったら、
片方は `heading-1` に落とすか、画面を分ける。

## 字間（`letter-spacing`）

- 既定は触らない（`letter.spacing.normal` = `0em`）。**本文の字間を広げない。**
- `letter.spacing.wide`（`0.12em`）は `.rd-caption` だけが使う。効くのは
  **欧数字とかなの短い語**（`CAPTION`、`2026-09-08`、`12 GB`）で、日本語の文章に当てると
  むしろ読みにくくなる。長い和文には使わない。
- 大文字化（`text-transform: uppercase`）はクラスに含めない。日本語に効かないうえ、
  読み上げが崩れることがある。大文字で書きたいなら文字そのものを大文字で書く。

## 折り返し

| 指定                 | 当てるもの         | なぜ                                             |
| -------------------- | ------------------ | ------------------------------------------------ |
| `text-wrap: balance` | 見出し（数行まで） | 行の長さを揃えて、1 語だけ落ちる行を作らない     |
| `text-wrap: pretty`  | 本文・箇条書き     | 段落末の孤立行（オーファン）を避ける             |

どちらも Baseline Newly なので `@supports` の中だけに書く（効かない環境では素の折り返しに落ちる）。
長い本文に `balance` を当てない（行数が増えるほど計算が効かなくなる）。

## 行長（measure）

読む文章の 1 行は `--rd-sizing-measure-max`（80ch）で止める。`base.css` が `p` と `li` に、
`.rd-prose` が入れ物ごとに当てている。表・コード・ナビはこの対象ではない
（横に溢れるものは入れ物を `overflow-x: auto` にして転がす）。

## 省略

- `.rd-truncate` は 1 行、`.rd-clamp` は `--rd-clamp-lines`（既定 3）行で切る。
- **切った文字は読み上げには残る**が、目で読む人には失われる。**押せるもののラベルを切らない**
  （何をするか分からなくなる）。切るなら全文が読める場所（詳細画面・`title` ではなく本文）を必ず用意する。
- 幅は入れ物が決める。クラス側に幅を書かない。

## 流し込み本文（`.rd-prose`）

CMS や Markdown の出力のように、クラスを付けられない HTML はこれで包む。

```html
<article class="rd-prose">
  <h2>雨の日の窓</h2>
  <p>…</p>
</article>
```

中の要素セレクタは `:where()` で詳細度 0 にしてあるので、**利用側のクラスが必ず勝つ**。
色は `text.default` / `text.muted` / `accent.text` の 3 つしか使わない。

## やらないこと

- 太さを 3 段にしない（`regular` と `bold` の 2 段だけ）。中間の太さはスタックに無いことが多い。
- 大きさを増やさない。`display` + 見出し 4 段 + 本文 + 小 + キャプションで足りないなら、
  足りないのは大きさではなく余白か階層。
- 色で見出しを作らない（大きさと太さで作る）。意味色は文字の色に使わない。
- Web フォントを同梱しない（[docs/brand.md](../../docs/brand.md) §6）。
- `px` で字を指定しない。利用者のブラウザ設定が効かなくなる。
